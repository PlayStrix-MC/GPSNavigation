# GPSNavigation (Purpur / Paper 1.21.11)

Плагин навигации к NPC по дорожной сети: логические маркеры, мёртвые зоны, A*, персональные указатели и GUI-путеводитель.

## Сборка

Нужен JDK 21.

```
./gradlew build        # Windows: gradlew.bat build
```

Готовый jar: `build/libs/GPSNavigation-<версия>.jar` (версия — `pluginVersion` в `gradle.properties`) → положить в `plugins/` сервера Purpur 1.21.11.

Зависимости (compileOnly):
- `io.papermc.paper:paper-api:1.21.11-R0.1-SNAPSHOT` из `repo.papermc.io`;
- DisplayLib — положите его jar в папку `libs/` (в репозиторий не входит). На сервере DisplayLib необязателен: без него плагин работает с пакетными указателями и меню-инвентарём.
Для офлайн-проверки компиляции можно подставить свой jar API: `gradlew build -PlocalApiJar=путь/к/api.jar`.

## Быстрый старт администратора

1. `/gpsmap create town Город` — карта в текущем мире (автоматически выбирается для редактирования).
2. `/road wand` — жезл «Дорожный маркер» (изумрудный блок). ПКМ по земле — маркер над блоком.
   Маркеры в радиусе 5 блоков по горизонтали и с перепадом высоты до 4 блоков соединяются автоматически,
   если между ними нет стен и мёртвых зон. Мосты, этажи и лестницы соединяйте вручную (Shift+ПКМ, до 16 блоков, без ограничения высоты).
3. `/road show` — показать сеть: ID над маркерами, линии связей (видит только включивший).
4. `/gpsnpc create blacksmith town Кузнец` — NPC в вашей позиции, привязка к ближайшему маркеру (радиус 5).
5. `/gpszone wand` — жезл мёртвых зон (бедрок). Ставьте точки вокруг области (например, горы): они соединяются сами, как маркеры, и вся площадь внутри замкнутого контура становится мёртвой зоной.
6. `/gps give <игрок>` — выдать GPS-путеводитель.

## Предметы

| Предмет | Материал | Команда | Право |
|---|---|---|---|
| GPS-путеводитель | KNOWLEDGE_BOOK (или `guide.item-model` из ресурс-пака) | `/gps give [игрок]` | `gps.give` (выдача), `gps.use` (использование) |
| Дорожный маркер | EMERALD_BLOCK | `/road wand` | `gps.admin.road` |
| Маркер мёртвой зоны | BEDROCK | `/gpszone wand` | `gps.admin.zone` |

Предметы распознаются только по PDC-метке `gpsnavigation:item`. Обычные изумрудные блоки, бедрок и книги знаний ничего не делают.
Специальные блоки никогда не ставятся в мир, книга знаний не расходуется, крафт из специальных предметов запрещён.

### Жезл «Дорожный маркер»
- **ПКМ по блоку** — создать маркер (ID вида `M-001` выдаётся автоматически; повтор в той же точке не создаёт дубликат).
- **ЛКМ по маркеру ×2** — удалить (граф, привязки NPC и активные маршруты обновляются).
- **Shift+ПКМ** по двум маркерам — связать вручную: до 16 блоков, любой перепад высоты, блоки не проверяются (только мёртвые зоны).
- **Shift+ЛКМ** по двум маркерам — разорвать связь.
- Пока жезл в руке, видна сеть и круг радиуса соединения вокруг точки прицела.

### Жезл «Маркер мёртвой зоны»
- **ПКМ по блоку** — поставить точку зоны (ID вида `Z-001`). Точки в радиусе `zone.link-radius` (5) соединяются автоматически.
- Когда соединения образуют замкнутый контур, вся площадь внутри (на всех высотах) — мёртвая зона: GPS не использует маркеры и связи в ней.
  Незамкнутые цепочки и «хвосты» ничего не перекрывают.
- **ЛКМ по точке ×2** — удалить. **Shift+ПКМ / Shift+ЛКМ** по двум точкам — соединить / разорвать вручную.
- В режиме показа точки и связи рисуются на своей реальной высоте: фиолетовые — контур замкнут, розовые — не замкнут.

## Путеводитель (игрок)

### С DisplayLib — экран перед игроком
ПКМ путеводителем открывает экран (видит только сам игрок):
- все NPC мира карточками по 6 на страницу: иконка, имя, описание (или «● Маршрут активен» / «Нет дороги к NPC»);
- клик по карточке — выбор: зелёная полоса слева «вырастает», появляется галочка, имя подсвечивается; повторный клик — снять выбор;
- внизу кнопка «Проложить маршрут ➜» (зелёная полоса), для уже активного маршрута — «Отменить маршрут ✕» (красная);
- ◀ ▶ и «Страница N из M» появляются только если NPC больше шести; ✕ в углу закрывает экран.

Вёрстка: `plugins/GPSNavigation/displaylib/screens/gps_navigator.jmc` (id виджетов не менять). Только меню-инвентарь: `gui.style: INVENTORY`.

### Без DisplayLib — меню-инвентарь
Рамка из серого стекла, внутри NPC, внизу кнопка «Выйти». Клик по NPC — маршрут, повторный клик — отмена.

Альтернативные команды: `/gps`, `/gps start <npc>`, `/gps stop`, `/gps status`.

## Команды

```
/gps [start <npc>|stop|status|give [игрок]|reload]
/road wand|show|info [id]|remove <id>|link <a> <b>|unlink <a> <b>|list [карта]
/gpszone wand|show|list [карта]|here|info [id]|remove <id>|link <a> <b>|unlink <a> <b>
/gpsnpc create <id> <карта> [имя]|remove <id>|move <id>|rename <id> <имя>|desc <id> <текст|clear>|icon <id> <предмет>|relink <id>|list [карта]|info <id>
/gpsmap create <id> [имя]|select <id>|list|remove <id> confirm|rename|desc|icon <id> <значение>
```

## Права

`gps.use`, `gps.give`, `gps.admin.road`, `gps.admin.zone`, `gps.admin.npc`, `gps.admin.map`, `gps.admin.debug`, `gps.admin.reload`, а также `gps.admin.*` (все административные).

## Данные

`plugins/GPSNavigation/`: `maps.jmc`, `markers.jmc`, `zone-points.jmc`, `npcs.jmc` — в формате [Jumper](https://github.com/jumper-lang/jumper), как и `config.jmc`. Сохраняются сразу после изменений (асинхронно, через временный файл) и при выключении сервера. Старые `*.yml` при первом запуске переносятся автоматически и переименовываются в `*.yml.old`. Счётчики `nextNumber` гарантируют, что ID `M-xxx`/`Z-xxx` не переиспользуются.

## Визуализация

### С DisplayLib (рекомендуется)
Если на сервере установлен [DisplayLib](https://github.com/Pa-dej/DisplayLib/releases) (Paper 1.21.11), маршрут рисуется «тропой Ока Края»:
- в узлах маршрута (каждые 3 блока, до 17 блоков вперёд) — светящееся зелёным Око Края, медленно вращается;
  узлы стоят невысоко над землёй и идут по рельефу (склоны, ступеньки), не уходя в блоки;
- от каждого узла к следующему бежит поток зелёных искр — видно направление;
- вокруг целевого NPC поднимается золотая спираль, сама сущность NPC светится контуром;
- по прибытии — всплеск звёзд.

Это display-сущности, которые DisplayLib шлёт пакетами только игроку с маршрутом: на сервере сущностей нет,
другие игроки ничего не видят, а отключённые частицы у клиента на них не влияют.
Эффекты лежат в `plugins/GPSNavigation/displaylib/particles/*.jmc` — их можно менять и перечитывать `/displaylib reload`.
Отключить: `displayLib = { enabled: false, ... }` в config.jmc.

### Без DisplayLib
- Указатели — снаряды шалкера пакетами только игроку с GPS (`pointer.mode: PACKET`), со свечением.
- Цель — сущность NPC светится контуром только у игрока с маршрутом; если сущности нет — светящийся указатель над точкой NPC.
- Если пакеты недоступны на ядре — запасной режим со скрытыми несохраняемыми сущностями (предупреждение в консоли).

Сущность NPC для свечения: `/gpsnpc bind <id>` (посмотреть на неё) или автоматически ближайшая к точке NPC (в т.ч. Citizens).
Отладка `/road show` для админов — частицы и подписи, видимые только включившему.

## Сборка с DisplayLib
`libs/displaylib-api-stub.jar` — заглушка API DisplayLib только для компиляции (в итоговый jar не попадает).
Можно заменить её настоящим `DisplayLib-*.jar` из релизов.

## Конфиги на Jumper

Все файлы плагина — `.jmc` (Jumper config): переменные верхнего уровня, таблицы `{ ключ: значение }`, массивы `[...]`, комментарии `//`. Ошибка в файле данных не стирает его: плагин копирует файл в `*.jmc.broken` и пишет ошибку в консоль. Библиотека Jumper 0.12.0 (MIT) встроена в плагин в пакете `com.gpsnavigation.lib.jumper` и не конфликтует с копией внутри DisplayLib.
